NYOTA FOUNDATIONS — WEBSITE
===========================
Domain: mission.nyotacore.com.ng

DEPLOY ON CPANEL
----------------
1. cPanel > File Manager > open "public_html".
2. Upload the zip, then right-click > Extract. Delete the zip afterwards.
   Keep the folder STRUCTURE intact — do not flatten it. It must look like:
        public_html/index.html
        public_html/about.html
        public_html/donate.html
        public_html/contact.html
        public_html/style.css
        public_html/main.js
        public_html/favicon.svg
        public_html/send.php                         (contact form mailer)
        public_html/private/config.php               (your settings - see below)
        public_html/phpmailer/src/...                (required by send.php)
        public_html/payment/online/callback/index.php (Paystack verify)
3. Make sure the domain/subdomain document root points to this public_html.
4. Visit https://mission.nyotacore.com.ng — done.

PHP is required (contact form + payment verify). cPanel has PHP by default.

DONATIONS (Paystack)
--------------------
* Currently TEST keys — no real money moves. Use Paystack test cards to try it.
* Put your public key (pk_test_... / pk_live_...) in donate.html, and your
  secret key (sk_test_... / sk_live_...) in private/config.php.
* In your Paystack dashboard, set the callback URL to:
      https://mission.nyotacore.com.ng/payment/online/callback
* SECURITY: the secret key (sk_...) must NEVER appear in any .html or .js
  file. Keep it only in private/config.php.

CONTACT FORM (SMTP)
-------------------
Copy private/config.example.php to private/config.php and fill in your
SMTP host, port, encryption, user and password, plus the inbox (mail_to).
If email fails to send, confirm your host allows outbound SMTP on that port.
